# Contribuir com o IIC

Shell iic_copilot, UI, testes de consumidor e implantação pertencem aqui.
Core, conectores, SDK, RAG, gateway, core-ui e operações comuns pertencem a
[Copilot Platform](https://github.com/marcos-slima/copilot-platform).
O domínio fiscal pertence ao [FISC](https://github.com/marcos-slima/fiscal-incident-support-copilot).

Use uv, dependências por versão/hash e app.sdk; não copiar o core para o produto.
Siga [execução](docs/GETTING_STARTED.md) e [qualidade](docs/QUALITY_GATES.md).
A branch padrão é master; PRs exigem uma revisão aprovada.
Não travar a branch como parte do fluxo normal de contribuição.

Mudanças editoriais atualizam [índice e mapa](docs/README.md), preservam evidências
históricas e não publicam versão de software. Não versionar dados de clientes ou segredos.
